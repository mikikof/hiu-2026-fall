FIGURE · 三層の順序

ハードウェアに近いのは、どれか

周辺機器を制御・操作するもの、基本的な管理と共通機能を担うもの、その上で用途向けの機能を担うもの。この 3 つを ハードウェアから近い順 に並べると、そのまま前の節で見た層の順序になります。

なぜ一番下がドライバか

ドライバがあって、OS が動かせる

デバイスドライバがインストールされることで、オペレーティングシステムが周辺機器を動作させることができます。機器に触れる側にいちばん近いので、いちばん下です。

なぜ一番上がアプリか

アプリは OS の機能を使って動く

アプリケーションソフトウェアは、OS が提供する機能を利用して動作します。オペレーティングシステムの上で、特定の作業を行うために使われるソフトウェアです。

オペレーティング（operating）には「運用、操作」などの意味があります。コンピュータの基本的な管理・制御を行うソフトウェア、という定義とそのまま重なります。

EXTRA

OS が貸すもの

記憶の場所と、ファイルの置き場所

EXTRA 1 / 記憶の割り当て

アプリを開くと、OS が場所を貸す

アプリは、自分で主記憶の場所を選んでいるわけではありません。開くときに OS が用意し、閉じると返してもらいます。

開くと用意する

アプリを開くと、OS がそのアプリ専用の記憶の場所（仮想アドレス空間）を用意します。共有しない限り、ほかのアプリからは使えません。

閉じると解放する

アプリを閉じると、そのアプリに割り当てられていた資源（記憶の場所など）は解放されます。

足りなくなったら

主記憶が足りなくなると、OS は主記憶の中身の一部をディスクへ移します。前回の記憶の階層で見た、遠い置き場所です。

前半とのつながり

配列は、アプリから見ると続いた場所

前半の配列は、続いた番地に順番どおりに並ぶので、位置から場所を計算できました。その「続いた番地」は、アプリから見た番地の上のことです。OS は表（ページ テーブル）を使って、アプリの番地を主記憶の実際の位置に置き換えます。

OS の目的とのつながり

資源の有効利用

限られた主記憶を、開いているアプリに分けて貸し、閉じたら返してもらう。これが、この回の OS の目的の 1 つ「資源の有効利用」の具体的な姿です。

EXTRA 2 / FAT の表

ファイルの続きは、表でたどる

USB メモリや SD カードでよく使う FAT（File Allocation Table）という形式では、記憶装置の場所をクラスタという単位で割り当て、表でつなぎます。

クラスタ
記憶装置の場所を割り当てる単位です。データを置くクラスタの番号は 2 から始まります。
フォルダーの項目
ファイルの名前などと一緒に、ファイルの最初のクラスタの番号が書いてあります。
FAT の表
1 つの欄に、そのファイルの次のクラスタの番号か、終わりの印が入っています。空いているクラスタの欄は 0 です。
断片化
1 つのファイルが、離れたクラスタに分かれて置かれた状態です。Windows のデフラグは、断片化したファイルを探してまとめ、システムの性能を上げます。
表の欄が次の番号を持ち、最初から順にたどってファイルの中身を集めます
前半とのつながり

表の欄は、リストの鎖と同じ

前半のリストは、荷ごとに次の荷の番地を持っていました。FAT の表の欄も、次のクラスタの番号を持っています。Microsoft の仕様書は、この表を singly linked list（単方向の連結リスト）と呼んでいます。

前半とのつながり

3 つ目のクラスタは、最初からたどる

ファイルの 3 つ目のクラスタを知るには、フォルダーの項目の最初の番号から、表を 2 回たどります。前半の「k 番目には先頭から辿る」と同じです。

EXTRA 3 / 身近な実物

形式の名前と、メモリの使用量を見る

フォーマットのときに出る形式の名前や、アプリが使っているメモリの量は、手元のパソコンでも確かめられます。

いまのパソコンの既定

いまの Windows の既定のファイルシステムは NTFS、macOS 10.13 以降の Mac は APFS です。どちらも FAT ではありません。

Mac のアクティビティモニタ

プロセス（アプリなど）ごとに、使っているメモリの量を見られます。「メモリ」をクリックすると、ウインドウの下部にメモリ全体の使われ方が出ます。

Windows のタスク マネージャー

実行中のアプリのメモリ使用量を見られます。Ctrl＋Shift＋Esc キーで開きます。［スタート］を右クリックして［タスク マネージャー］を選んでも開きます。

フォーマット

形式を選ぶと、表を作り直す

Windows の format コマンドで指定できる形式には、FAT・FAT32・NTFS・exFAT があります。exFAT も、次のクラスタの番号をつなぐ FAT の表を持っています。

SSD の場合

デフラグとは別の手入れ

Windows は、SSD にはデフラグとは別の「トリム」という手入れをします。既定では、週に 1 回ドライブを自動で最適化します。
