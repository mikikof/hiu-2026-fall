PART 3 ／ while・break
条件で繰り返す・途中で​止める
while で続ける​条件を書き、​break で繰り返しの​途中から​抜けます。
while の形止まらない​ときbreak使い分け練習③


while ／ 形
while 文の​継続条件
合計が100以下の​あいだ、​次の​数を足します。​while の​条件は、​繰り返す前に毎回​調べます。
Colab に打つ
total = 0
i = 0
while total <= 100:
    i = i + 1
    total = total + i
print(i, total)
覚える​こと
while は​条件が False に​なると抜けます。​足して​合計が100を超えた​あとに、​次の​条件を調べます。


while ／ 止まらない
止まらない​繰り返しの​停止
i を増やす行を忘れると、​合計が増えず、​total <= 100 は​ずっと True のままです。
Colab に打つ
i = 0
total = 0
while total <= 100:
    total = total + i
i が0のままなので、​total も​0のままです。​この​コードは​何も​表示せず、​実行が続きます。
各自の​画面で打つ
Colab に打って​実行し、​セル左の​停止ボタンで止めます。


break ／ 途中で​抜ける
0を打った​ときの​終了
0を打つまで、​課題にかけた分を足します。​0を受け取ったら、​足す前に break で​抜けます。
Colab に打つ
total = 0
while True:
    fun = int(input('課題にかけた分（0で終了）: '))
    if fun == 0:
        break
    total = total + fun
print(f'合計 {total} 分')
覚える​こと
while True は​条件だけでは​終わりません。​break で繰り返しを​抜けると、​最後の​ print が1回動きます。


使い分け ／ 早見
for と while の​使い分け
回数が先に決まる​ときは​ for、​続ける​条件で決まる​ときは​ while を使います。
for ／ 1から​nまで順に足す
Colab に打つ
n = 5
total = 0
for i in range(1, n + 1):
    total = total + i
print(total)
15
while ／ i が​ n 以下の​あいだ足す
Colab に打つ
n = 5
total = 0
i = 1
while i <= n:
    total = total + i
    i = i + 1
print(total)
15
while の​例では、​i を増やす行も​自分で書きます。
