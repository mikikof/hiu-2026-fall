プログラミング入門 ／ 手元の PC

Python 導入マニュアル

手元の PC に Python と VS Code を入れる手順です。Windows と Mac に分けて書いています。

授業は Google Colab で進めます。手元の PC に Python を入れなくても、授業は最後まで受けられます。このページは、自分の PC でも Python を動かしたい人のための手順です。入れるかどうかは、各自で決めてください。

2026年10月11日の時点の公式のページと配布物で確かめた内容です。画面の見た目は版によって変わります。図は画面の形をまねて描いたもので、細かいところは実際の画面と違います。

入れる PC を選ぶと、その PC の手順だけが出ます。

入れるとできること

ネットが無いときの実行

Python 本体が自分の PC に入るので、インターネットにつながっていなくてもプログラムを動かせます。

手元に残るファイル

Colab で %%writefile を使って作ったファイルは、しばらく操作しないでいるとつながりが切れて消えます。手元の PC では、作ったファイルが自分のフォルダーに残ります。

入れるものと要るもの

Python 本体

Python のプログラムを動かすものです。入る版は 3.15 です（2026年10月9日に出た、いまの最新の版）。

VS Code

プログラムを書いて動かすためのエディターです。

拡張機能

VS Code に機能を足す部品です。Python 拡張と Jupyter 拡張の 2 つを入れます。

Python 本体 手順 1〜4

始める前の注意

前に Python を入れたことがある PC では、手順 2 で古い Python についての知らせが出たり、手順 4 で古い版の番号が出たりすることがあります。そのときは、その手順の「うまくいかないとき」を開きます。

Python を入れる前は、ターミナルで python3 と打たないでください。打つと、Apple の開発用のツール（コマンドラインデベロッパツール）を入れるかを聞く窓が出ます。その窓からツールを入れると、Apple の古い python3 が入ります。窓が出たら「キャンセル」を押します。

11 の手順を上から順に進めます。終えた手順に「できた」の印を付けると、上の帯に進み具合が出ます。印は、このブラウザに残ります。

手順 1 Python Install Manager の入手インストーラーのダウンロード

Python Install Manager は、Python 本体を入れたり新しい版に上げたりするための、Python の公式の道具です。python.org は、Windows ではこの道具を Microsoft Store から入れる方法を勧めています。

すること
  1. Microsoft Store のアプリを開き、上の検索欄に Python Install Manager と打ちます。ブラウザで下のリンクを開き、そこから Store のアプリへ進むこともできます。
  2. 発行元が Python Software Foundation の「Python Install Manager」を選びます。
  3. 入れるためのボタンを押します（表示は「入手」か「インストール」のどちらかです）。
  • Microsoft Store の Python Install Manager
  • python.org の Python Install Manager のページ
名前に版の番号が入った「Python 3.13」「Python 3.12」などのアプリは選びません。Store には、3.14 から版ごとのアプリが出ていません。

手順 2 設定チェックと本体のインストールPython のインストール

Python Install Manager を初めて開くと、設定チェックが動きます。設定チェックは、PC の設定を確かめて、足りないものを入れるかを英語で聞いてくる画面です。

すること
  1. スタートメニューで Python install manager を選んで開きます。
  2. 黒い画面に英語の説明と問いが出ます。問いの行は [y/N] か [Y/n] で終わります。どの問いにも、何も打たずに Enter を押します。
  3. Python 本体がまだ入っていなければ、続けて Python 3.15 のダウンロードとインストールが進みます。終わるまで画面を閉じずに待ちます。
  4. インストールのあと、設定チェックが終わったという意味の英語の行と、命令の一覧が出ます。最後に、ヘルプを開くかの問いが出ます。ここでも Enter を押せば、設定チェックは終わりです。画面がひとりでに閉じなければ、右上の × で閉じます。
[y/N] は Enter だけで No、[Y/n] は Enter だけで Yes を選んだことになります。Enter だけで答えると、Windows の設定は変えずに、Python 本体だけが入ります。出てくる問いの数は PC によって違います。

すること
  1. ダウンロードのフォルダーの python-3.15.0-macos11.pkg をダブルクリックします。確認の窓が出たら、「開く」か「続ける」を押します（「キャンセル」は押しません）。
  2. 「続ける」を押します。次の画面は英語の説明（Read Me）なので、もう一度「続ける」を押します。
  3. 使用許諾の画面で「続ける」を押し、上から出てくる確認で「同意する」を押します。
  4. 「インストールの種類」の画面では何も変えずに「インストール」を押します。「カスタマイズ」は押しません。
  5. 管理者の確認が出たら、Touch ID に触れるか、Mac にログインするときのパスワードを入れて進めます。
  6. 入れている途中で、Finder に「Python 3.15」のフォルダーの窓が開きます。この窓は閉じずに残します。
  7. 終わりの画面で「閉じる」を押します。インストーラーをゴミ箱に入れるかを聞かれたら、どちらを選んでもかまいません。
  8. 「Python 3.15」の窓の Install Certificates.command をダブルクリックします。ターミナルが開いて、英語の行が出ます。

手順 3 ターミナルの起動

ターミナルは、文字で命令を打って PC を動かす画面です。

すること
  1. スタートボタンを右クリックし、出てきたメニューの「ターミナル」を押します。Windows 10 では「Windows PowerShell」を押します。
  2. 「ターミナル (管理者)」は選びません。
授業のスライドで $ と書いた入力待ちの印は、Windows では > です。打たなくてよい部分です。PS C:\Users\（名前）> のような行が出て、> のあとに命令を打ちます。このページでは、命令の前に薄い > を付けています。コピーされるのは命令だけです。
見えるもの
PS C:\Users\名前>
できたかの確かめ方

PS で始まって > で終わる行が出て、文字を打てる状態になっています。

ターミナルは、文字で命令を打って Mac を動かす画面です。

すること
  1. Command（⌘）キーを押しながらスペースバーを押して Spotlight を出し、ターミナル と打って Return を押します。
  2. Python を入れる前から開いていた窓や、[プロセスが完了しました] で止まった窓は使いません。そうした窓が前に出たときは、⌘+N を押して新しい窓を開きます。
授業のスライドで $ と書いた入力待ちの印は、Mac では % です。打たなくてよい部分です。（名前）@（機種名） ~ % のような行が出て、% のあとに命令を打ちます。このページでは、命令の前に薄い % を付けています。コピーされるのは命令だけです。
見えるもの
名前@機種名 ~ %
できたかの確かめ方

% で終わる行が出て、文字を打てる状態になっています。

手順 5 VS Code のインストール

VS Code（Visual Studio Code）は、Microsoft が無料で配っているエディターです。エディターは、プログラムのような文字を書くためのアプリです。VS Code は毎週更新されるので、版の番号はこのページを作った時点の 1.141 より進んでいることがあります。

すること
  1. 下のリンクから、VS Code のダウンロードのページを開きます。
  2. Windows の欄の下の一覧（Other Downloads）で「User Installer (x64)」を選んで、ダウンロードします。Snapdragon などの Arm の PC では「User Installer (Arm64)」を選びます。Arm の PC かどうかは、設定の「システム」→「バージョン情報」の「システムの種類」に ARM とあるかで分かります。
  3. ダウンロードした、名前が VSCodeUserSetup で始まる .exe をダブルクリックします。右クリックの「管理者として実行」は使いません。
  4. 使用許諾の画面で「同意する」を選び、「次へ」で進みます。「追加タスクの選択」の画面では、最初から付いている印をそのままにします。
  5. 「インストール」を押し、終わったら「完了」を押します。
  • VS Code のダウンロードのページ
初めて開いたときに、サインインを勧める画面や、右側にチャットの欄が出ることがあります。このマニュアルの手順にサインインは要らないので、その画面は閉じてかまいません。

ほかの入れ方

次の入れ方もありますが、このマニュアルでは使いません。

Anaconda
無料で使えるのは、個人が自分のために非商用で使う場合などです。大学の授業として使う場合は、大学が対象の機関に当たり、学生一人ずつが学術向けの使用許諾に同意して毎年更新する必要があります。この大学が対象に当たるかは、確かめられていません。
Windows の従来のインストーラー（.exe）
Python 3.15 を最後に作られなくなります。PATH に足す印が最初は外れていて、python3 という命令も入りません。
Microsoft Store の「Python 3.13」などのアプリ
版ごとのアプリは、3.14 から Store に出ていません。
Homebrew
macOS 15 以降が要ります。Homebrew の Python は、仮想環境（プロジェクトごとに分けた Python の置き場）の外では pip install が止まります。python.org のドキュメントは、Python の開発の中心のチームが手入れしていない配布として挙げています。
uv
既定では、python3.15 のような版の番号つきの名前の命令しか入りません。入る Python も、python.org の配布物とは別に作られたものです。
